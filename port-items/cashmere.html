Cashmere
Component Library & Style Guide. 2017–present

Cashmere is an open source design system used by healthcare tech company Health Catalyst.

We created it in 2017, and have grown it from a humble style guide with a few Angular components into a fully fledged design system that supports dozens of applications and projects.

As of 2026, we’re undertaking a complete rewrite of Cashmere, with a major visual facelift and a modernized technical foundation. The screenshots below showcase the design system before this ongoing overhaul.
